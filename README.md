# LongPressDraggable Demo

A Flutter app that demonstrates how LongPressDraggable can be used to
create a simple drag-and-drop interaction.

## How to Run

1. Install Flutter.
2. Clone this repository.
3. Open the project in VS Code or Android Studio.
4. Run:

flutter pub get

5. Connect an Android phone or start an emulator.
6. Run:

flutter run

## Three LongPressDraggable Properties

### 1. data

Explain in your own words what `data` does.

In my project, the draggable sends the value `purple_card`
to the DragTarget.

### 2. feedback

Explain in your own words what `feedback` does.

In my project, the "Dragging!" card follows the user's finger
while the card is being dragged.

### 3. childWhenDragging

Explain in your own words what `childWhenDragging` does.

In my project, the original card changes to "Drag in progress"
while the user is dragging.
